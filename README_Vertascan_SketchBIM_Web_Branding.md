# Vertascan SketchBIM — Web Branding Edition

This version standardizes the browser tab title, in-app welcome branding, favicon, metadata, home-screen icon and printable register title.

## Publishing
1. Upload every file in this ZIP to the **root** of your selected GitHub Pages publishing directory; `index.html` must be at that root.
2. Enable Pages deployment in repository settings. If your repository is named `sketchbim`, its URL is typically `https://YOUR-USERNAME.github.io/sketchbim/`; project URLs are determined by the repository and account names.
3. For a custom domain, configure GitHub Pages and DNS, then optionally add a `CNAME` containing your actual domain. No domain was assumed or invented in this package.
4. Refresh cache after deployment. Social preview descriptions depend on crawler support and may require a publicly accessible URL.

**Important:** Web metadata does not change an actual host URL. The HTML opens from any path, including a local file; a standalone data-URL favicon fallback is embedded. This release does not modify the modeling engine.
